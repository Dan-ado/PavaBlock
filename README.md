# PavaBlock
## Chrome Extension: Website Blocker
This is an open-source Google Chrome extension designed to block unwanted websites, helping users stay focused or protect others from accessing inappropriate content. The extension allows users to block specific websites either permanently or for a set duration, while tracking access attempts with timestamps. It is 100% free, fully customizable, and built to serve a wide audience, including parents restricting adult content, students avoiding distractions like social media, or individuals combating compulsive browsing habits (e.g., gambling or news sites).
## Key Features:
- Website Blocking: Block specific URLs with options for permanent or temporary restrictions.
- Access Attempt Tracking: Logs the date, time, and URL of each blocked access attempt.
- Customizable: Users can add, remove, or configure blocked sites via an intuitive interface.
- Open Source & Free: Licensed under MIT, ensuring accessibility and transparency.
- User-Friendly: Simple popup and options pages for easy management.

## Use Cases:
- Parents protecting children from adult or harmful websites.
- Students blocking social media to focus on studies.
- Individuals curbing excessive visits to distracting or addictive websites.

## Installation:
1. Clone the repository.
2. Open Chrome and navigate to chrome://extensions/.
3. Enable "Developer mode" and click "Load unpacked."
4. Select the extension folder to install.
